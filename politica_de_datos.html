Política de Datos

Nuestra Política de Datos

En Eye Rest, valoramos tu privacidad y nos comprometemos a proteger tus datos personales. Esta política explica cómo recopilamos, usamos y compartimos tu información cuando utilizas nuestros servicios.

Recopilación de Datos

Recopilamos datos personales para ofrecer nuestros servicios de manera efectiva. Esto incluye:

  • Nombre, correo electrónico y número de teléfono.
  • Información necesaria para reservas y consultas.

Uso de Datos

Utilizamos tus datos para:

  • Proveer servicios personalizados.
  • Contactarte para confirmar citas o responder preguntas.
  • Cumplir con requisitos legales.

Compartición de Datos

No compartimos tus datos con terceros sin tu consentimiento, excepto cuando sea necesario para cumplir con la ley.

Tus Derechos

Tienes el derecho de acceder, rectificar o eliminar tus datos personales en cualquier momento. Contáctanos para más información.
